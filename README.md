# Sistema de Cadastro em C

Sistema simples de cadastro desenvolvido para praticar estruturas de dados e manipulação de informações utilizando a linguagem C.

## Funcionalidades

* Cadastrar pessoas
* Armazenar nome, idade e e-mail
* Listar pessoas cadastradas
* Menu interativo

## Tecnologias

* C

## Conceitos praticados

* `struct`
* Vetores
* Funções
* Strings
* `for`
* `do/while`
* `switch/case`
* Entrada e saída de dados
